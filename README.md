# 健康提醒（health-reminders）

久坐健康提醒 DSH 插件：按固定健康间隔定时提醒喝水与起身站立，面向长期久坐的程序员。**安装即默认开启**，无需手动配置。

## 提醒间隔

- 💧 喝水：每 60 分钟（约每小时一杯，一天约 8 杯 ≈ 2L）
- 🧍 站立：每 30 分钟（起身活动 1~2 分钟，打破久坐）

## 使用

安装后在任意会话自动开启。可用斜杠命令手动控制：

| 命令 | 作用 |
|---|---|
| `/health on` | 手动开启（幂等） |
| `/health off` | 关闭当前会话的提醒 |
| `/health status` | 查看当前提醒与间隔 |

## 说明

- 提醒只在 DSH 运行时投递（harness 内提醒，非 OS 级闹钟）。
- 按会话绑定：在哪条会话打开就投递到哪条；`/health off` 在重开会话/重启后会重新开启（默认开启语义）。

## 技术实现

注册 `/health` 斜杠命令，基于 DSH Host `schedule` 服务创建两条循环提醒；监听 `agent/created` 事件在会话进入时自动创建（幂等）。
